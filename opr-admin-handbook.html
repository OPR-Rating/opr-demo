OPR Club Admin Handbook

How to run your club on OPR

Members · Scores · Tournaments · Ladders · Backups — everything an admin does, step by step.

1 · Getting into Admin Control

  1. Open your club's app (phone) or desktop link (laptop — best for admin work).
  2. Tap Admin and enter your club admin PIN (in your welcome pack).
  3. The Admin Control Room opens with four tabs: Members · Tournaments · Matches · Club.

Your PIN manages your club only. Keep it with the committee — anyone holding it can add and edit members, fix scores and run tournaments.

Desktop is the admin's friend. The laptop version has everything the phone has, plus bulk member upload, Excel/PDF export on every table, and more room to work.

2 · Members

Add one member

Admin → Members → fill in Name, Gender (M/F), Initial Rating, PIN → Add member. The player appears on the ladder immediately at their starting rating.

  • Initial rating — their starting point on the scale (Men 1000–1800, Ladies 900–1500; defaults Men 1500 / Ladies 1300). See the Starting Ratings & Levels guide for how to choose.
  • PIN — the member's personal 4-digit code for entering their own scores. They can change it later.

Bulk add (desktop) — the 5-minute club setup

  1. In Excel, make 4 columns: Name · Gender · Initial Rating · PIN (one row per member).
  2. Copy the rows → Admin → Members → paste into the Bulk add box → Add all pasted members.
  3. Any faulty row is reported by line number; fix and re-paste just that line.

Edit or remove a member

Each member row has edit and del. You can correct name, gender, PIN — and the initial rating.

Important: editing a member's initial rating re-bases that player — the engine automatically recomputes the whole club's ratings from the new starting point (give it a few seconds, then refresh).

Just added members but they're not in the score-entry dropdowns? Refresh the page — player lists load when the page opens.

Club name

Admin → Members → Club name box changes the name shown on your front page for all members.

3 · Scores — entering and fixing

Three ways a score gets entered

  • Player — any member enters the match with their own PIN (front page → ✚ Enter score).
  • Club admin — enter on behalf of players using the club admin PIN (ideal on a reception laptop/tablet).
  • Every match records who entered it — visible in Admin → Matches.

Choose the Event (Social, Ladder Match, or a running tournament), the match type, the four players, and the set scores. Ratings recompute automatically the moment a match is saved.

Duplicate guard: if the same four players were recently entered, the app warns you (naming who and when) before saving — Cancel saves nothing.

Fixing or deleting a match

Admin → Matches lists recent matches. Open one to fix a wrong score or event type, or delete it entirely. Ratings recompute automatically after any change — no further steps.

4 · Tournaments

Internal vs External — which to pick

  • Internal — the full club tournament engine: divisions (Men's, Ladies, Mixed, All Sorts), team caps, automatic Swiss draws, rounds, standings, semi-finals and a final. Use this for your club events.
  • External — a simple named event without the divisional structure: matches are tagged with the tournament's name and tracked in the tournament statistics. Use it for away days, friendlies or events run outside the draw engine.

Create an internal tournament

  1. Admin → Tournaments → enter a name (e.g. "Summer Swing") and choose type Internal.
  2. Tick the divisions you're running — Men's and Ladies are on by default; add Mixed and All Sorts if wanted.
  3. Set each division's team cap — even numbers, minimum 4 (the pairing engine needs even fields). Caps can be extended later from the same tab if demand grows.
  4. Create tournament. It now appears as an Event choice and on the Current Tournaments page.

Entries, seeding and the draw

  • Enter each pair into its division. A pair's seed rating is frozen at entry time — later rating moves don't reshuffle the seeding, which keeps the draw fair and stable.
  • When the field is in, generate the draw. OPR uses a banded Swiss system: pairs meet opponents of similar seeding, and each round is built from results so far — competitive matches all the way through.
  • After the rounds, run the Semi-Finals and Final bracket from the standings.

Playing and scoring tournament matches

Tournament scores are entered through the normal ✚ Enter score flow — just choose the tournament as the Event. The result files itself against the right fixture automatically, and standings and statistics update. Fixtures show on the Current Tournaments page for everyone to follow.

Even teams only: a division can't generate a draw with an odd number of pairs — keep entries even (minimum 4 per division).

Finishing up

When the event's done, archive the tournament — its results are preserved in the tournament archive and it disappears from the active Event list.

5 · The Good 'ol Club Ladder

  1. Open the Club Ladder page, pick the category, and (as admin) Activate the ladder — a one-time step that sets the starting order.
  2. Once active, members play Ladder Matches: enter the score with Event = Ladder Match, and positions update by the ladder's challenge rules.
  3. Need a fresh start? Admin can Re-activate a ladder — this resets the order, so use deliberately.

If someone picks "Ladder Match" before any ladder is activated, the app tells them so — activate first, then play.

6 · Backups

Admin → Matches → Full club backup downloads a single date-stamped file containing your entire club: members and ratings, every match, all tournaments (draws, entries, archives), the ladder — everything.

  • Take one before anything significant (a big tournament, a bulk change) and monthly as routine.
  • Store it somewhere safe (cloud drive). It's your club's complete restore point.

7 · Quick troubleshooting

  • New members missing from dropdowns → refresh the page (lists load at page-open).
  • Something looks outdated after an update → hard refresh: Ctrl+F5 (computer) or close and reopen the app (phone).
  • "No active ladders" when entering a Ladder Match → activate the ladder first (Section 5).
  • Ratings look unchanged after a fix → recomputes take a few seconds; refresh once more.
  • PIN not accepted → PINs are exact 4-digit codes; check you're on the right club's app.
  • A member forgot their PIN → Admin → Members → edit → set a new PIN.
